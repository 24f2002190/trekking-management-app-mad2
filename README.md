Trekking Management Application

A web-based application for managing trekking events, staff, and participant bookings.

Features
Admin can manage treks, staff, and users.
Trek Staff can update trek details and view participants.
Users can register, browse treks, and make bookings.
Search and filter treks by location, difficulty, and duration.
Prevents overbooking and duplicate bookings.
Generates reports and booking history exports.
Tech Stack
Frontend: Vue.js, Bootstrap
Backend: Flask
Database: SQLite
Caching: Redis
Background Jobs: Celery
